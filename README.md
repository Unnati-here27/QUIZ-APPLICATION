

# Quiz Application

A simple Quiz Application developed as a project to test users' knowledge through multiple-choice questions.

## Features

* Simple and user-friendly interface
* Multiple-choice questions
* Displays quiz questions and options
* Calculates the score automatically
* Shows the final result
* Allows the user to restart the quiz

## Technologies Used

* Java
* HTML
* CSS
* JavaScript

## How to Use

1. Open the Quiz Application.
2. Read each question carefully.
3. Select the correct answer.
4. Continue until all questions are completed.
5. View your final score.

## Project Objective

The main objective of this project is to create a simple and interactive quiz application while applying programming and problem-solving concepts.
